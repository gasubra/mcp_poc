# Modern Login System

A secure, modern login system built with FastAPI and modern web technologies.

## Features

- 🔐 **JWT Authentication**: Secure token-based authentication
- 🎨 **Modern UI**: Responsive design with gradient backgrounds
- 🛡️ **Security**: Bcrypt password hashing, HTTP-only cookies
- 📱 **Responsive**: Mobile-friendly design
- ⚡ **Fast**: Built with FastAPI for high performance

## Quick Start

1. **Install Dependencies**
   ```bash
   pip install -r login_app/requirements.txt
   ```

2. **Run Application**
   ```bash
   python login_app/main.py
   ```

3. **Access Login**
   Open: http://localhost:8000

## Security Features

- JWT tokens with configurable expiration
- Bcrypt password hashing
- HTTP-only cookies for XSS protection
- Input validation and sanitization
- Secure error handling

## Tech Stack

- **Backend**: FastAPI (Python)
- **Authentication**: JWT + bcrypt
- **Frontend**: HTML5 + Modern CSS
- **Templates**: Jinja2
